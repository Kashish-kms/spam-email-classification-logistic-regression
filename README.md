# Spam Email Classification using Logistic Regression

## Overview
This project implements a Logistic Regression model to classify emails as **spam** or **not spam**. It is a supervised machine learning project that uses the **Spambase dataset** and demonstrates the complete workflow from data loading to model evaluation.

## Aim
To implement a Logistic Regression model for spam email classification.

## Objectives
- Understand Logistic Regression
- Perform binary classification
- Evaluate the model using confusion matrix and performance metrics
- Apply the model on a real-world dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib (optional)

## Dataset
The project uses the **Spambase dataset**, where:
- `1` = spam
- `0` = not spam

Place the dataset file in your project folder before running the code.

## Project Workflow
1. Import required libraries
2. Load dataset
3. Separate features and target variable
4. Split dataset into training and testing sets
5. Train Logistic Regression model
6. Make predictions
7. Evaluate performance
